# Customer-SupportTicket-System

A console-based Customer Support Ticket Management System built using C++.

The project demonstrates Object-Oriented Programming (OOP), STL containers, priority queues, searching, sorting, input validation, and timestamp handling.

# Features
->Create new support tickets

->Automatically generate unique ticket IDs

->Assign ticket priority:
    High
    Medium
    Low
->Track ticket status:
    Open
    In Progress
    Resolved
->View all tickets

->Search ticket by ID

->Search tickets by customer name

->Update ticket status

->Process the next highest-priority ticket

->Close a ticket

->Permanently delete a ticket

->Display ticket creation timestamp

->View ticket statistics

->Validate user input
